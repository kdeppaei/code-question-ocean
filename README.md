# CodeDive 程式題海

以 LeetCode 式解題工作台為核心，結合繁體中文短篇教學的程式語言練習網站。

## 線上版本

[開啟 CodeDive 程式題海](https://codedive-practice-lab.kdeppaei2.chatgpt.site)

## 第一版內容

- C、C++、Python、SQL、GDB 五個專項
- 20 題原創練習，含難度、主題、範例、限制、提示與參考解答
- 題目搜尋與語言／難度篩選
- 左側題目、右側程式碼編輯器的解題工作台
- 教學版結構判題、範例測試與提交紀錄
- 15 篇繁體中文短篇教學，並連結相關練習
- 本機保存已解題目、錯題、收藏、每日目標與學習分析
- 響應式版面與深色模式

> 第一版採瀏覽器內的教學版結構判題，用來檢查解題關鍵結構；尚未執行不受信任的 C/C++/Python/SQL 程式碼。完整沙箱編譯與測試是後續可加入的功能。

## 本機開發

需要 Node.js 22.13 以上與 pnpm。

```bash
pnpm install
pnpm dev
```

正式建置：

```bash
pnpm build
```
